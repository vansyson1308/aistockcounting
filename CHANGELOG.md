# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-02-22
### Added
- MVP full stack: Next.js frontend, FastAPI backend, Postgres, MinIO, Nginx.
- CVAT labeling workflow and dataset tooling.
- YOLO training/evaluation/export pipeline and model registry docs.
- Production-lite operations package: CI/CD workflows, staging deployment, backups, runbook, and release playbook.
